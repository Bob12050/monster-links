# v8.6-A.30 初回導線強化

## 目的

初回プレイヤーが「次に何をすればよいか」で迷わないように、既存の任務掲示板とホームの「次にやること」を使って、短いチュートリアル導線を追加した。

## 追加したガイド任務

```text
tut_meadow_first   はじまり草原の通常探索で1回勝利
tut_scout_try      戦闘中にスカウトを1回試す
tut_equip_first    アクセサリーを1回装備
tut_boss_pressure  はじまり草原でボスの気配をためる
tut_meadow_boss    草原ボスを倒す、またはスカウト
tut_fusion_list    配合所を開いて配合リストを確認
```

## 実装メモ

- `group:"tutorial"` の任務を追加した。
- 任務掲示板に「はじめてガイド」セクションを追加した。
- `records.scoutAttempts` を追加し、スカウト成功・失敗とは別に「試した」回数を記録する。
- `records.views` と `recordView(view)` を追加し、配合所を開いたことを任務進捗に使えるようにした。
- ホームの「次にやること」は、受取可能な報酬がない時に未完了のガイド任務を案内する。
- セーブ形式番号は変更していない。旧セーブでは `records.scoutAttempts` と `records.views` を自動補完する。

## バランス方針

報酬は序盤の導線補助として控えめに設定した。能力値、配合結果、ステージ報酬、スカウト率、敵能力は変更していない。
