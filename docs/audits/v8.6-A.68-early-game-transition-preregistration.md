# v8.6-A.68 序盤から中盤への接続調整 事前登録

## 前試験から引き継ぐ判断

最初の固定候補 `finalist` はseed 86900・300周で5/7ゲートとなり、不採用にした。序盤4地域の戦闘数と通常戦敗北は改善したが、火山後の到達Lvが下がり、星晶の塔の戦闘数P90がバランス型で対照の125%を超えた。また収集配合型の火山初回撃破率が67%となり、旧上限65%を2pt超えた。

この結果から「難しい序盤を短縮する」と「中盤へ必要な育成量を渡す」を別の仕組みに分ける。通常ボスEXPを増やすと再戦稼ぎが成立するため、火山初回撃破時だけ付与する接続EXPを使う。

接続調整:

- 火山ボス初回撃破時だけ基礎2,500 EXPを追加（全体EXP倍率適用後2,900 EXP）。再戦・スカウト再挑戦では0。
- 火山ボス戦の「攻撃優先」だけ、HP30%以下かつ回復技を使える場合に緊急回復する。他方針・通常戦・他地域へは適用しない。
- 敵ID、表示Lv、必要勝利数、通常のボスEXP/GOLD、ドロップ、スカウト率、モンスター能力、セーブschemaは変更しない。

## なぜ方針別上限を分けるか

公開時の既定作戦は「バランス」であり、ここを主KPIとする。「速攻」は回復を抑える高リスク方針、「収集・配合」は仲間・回復を厚くする高準備方針なので、全方針を同じ初回撃破率へ寄せると作戦差を消してしまう。探索結果を見て候補値を変えず、ホールドアウト前に上限だけを次のように固定する。

## ホールドアウト

- seed: 87000（これまでの探索・ホールドアウトseedと別）
- 対照300周 / 候補300周、速攻・バランス・収集配合を各100
- 同じprofile・run番号・初期seedのpaired比較
- 1周400戦、1戦200ターン、各ボス敗北40回
- 序盤4地域が主対象、変更していない星晶の塔を波及ガードレールにする
- 結果確認後に候補値・seed・ゲートを変更しない

## 採用ゲート

1. 各方針の序盤4地域完走率98%以上。
2. 草原通常戦敗北率10%以下。
3. 序盤4地域の戦闘数P90を対照比でバランス型25%以上、他方針15%以上短縮。
4. 平均ボス挑戦はバランス型3回以下、収集配合型3.5回以下。速攻型は草原〜湖畔3.5回以下、火山8回以下。
5. 初回撃破率はバランス型60%以下、速攻型65%以下、収集配合型70%以下。
6. ボス解放後の追加通常勝利は草原〜湖畔5回以下、火山8回以下。
7. 星晶の塔は各方針の突破率が対照比-5pt以内、地域戦闘数P90が対照の125%以下。
8. 300 campaign / 1,500 stage rowsが各群で揃い、12周再実行の決定論署名が一致する。

## 制約

固定ボット方針の相対比較であり、実ユーザーの離脱率や主観難易度ではない。毎戦無料全回復を使うため導線を知らない初心者はより厳しく、手動の属性選択・交代を使う熟練者はより易しい可能性がある。接続EXPは、旧版で再挑戦・追加通常戦から得ていた育成量を初回撃破へ移す設計判断である。
